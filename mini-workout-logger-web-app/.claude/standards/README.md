# Coding Standards

Rules for writing code in the `mini-workout-logger-web-app` frontend. Every file lists numbered rules; the numbering is local to that file. When a rule is contradicted by an older pattern still in the codebase, the standards file is the source of truth — the code has not been migrated yet.

Inspired by the [BBC Simorgh coding standards](https://github.com/bbc/simorgh/tree/latest/docs/Coding-Standards), adapted to this project.

## Files

| File | Scope |
|---|---|
| [general.md](./general.md) | Global editor/tooling hygiene (ESLint) |
| [clean-code.md](./clean-code.md) | Code organisation, comments, functions, safe object access, boilerplate |
| [naming-conventions.md](./naming-conventions.md) | Casing per identifier kind, descriptive names, no appearance-based names |
| [react-components.md](./react-components.md) | Component structure, props, hooks, TypeScript strictness |
| [styles.md](./styles.md) | Emotion `css` prop, CSS variables, responsive strategy, style composition |
